# Apple Magic Trackpad Windows Precision Touchpad Driver v1.0.0

🎉 We are excited to announce the v1.0.0 release of the **Apple Magic Trackpad Windows Precision Touchpad Driver**!

This driver is a **100% native, driver-level solution** that transforms your Apple Magic Trackpad 2 & 3 into an official Windows Precision Touchpad (PTP). It gives you native Windows 10 & 11 gestures without running any third-party background software or paying for commercial tools like Magic Utilities.

### 📦 Download Assets
- **[`Apple-Magic-Trackpad-Precision-Driver-v1.0.0.zip`](Apple-Magic-Trackpad-Precision-Driver-v1.0.0.zip)** *(~250 KB — Recommended)*
  Contains the driver files and 1-click installer. Zero background software required.

---

### 🚀 Key Features:
1. **Full Native Windows Precision Touchpad (PTP) Integration**:
   - 2-finger smooth scrolling & fluid pinch-to-zoom.
   - 3-finger swipe up for Task View (all virtual windows).
   - 3-finger swipe left/right to switch between apps (Alt-Tab).
   - 4-finger swipe to switch between Virtual Desktops.
   - All settings directly configurable inside **Windows Settings ➔ Bluetooth & devices ➔ Touchpad**.

2. **Broad Hardware Compatibility**:
   - Apple Magic Trackpad 3 USB-C (Late 2024 / M4 - PID `0x0324`)
   - Apple Magic Trackpad 3 & 2 Lightning (PID `0x0265`)
   - Apple Magic Trackpad 2 (PID `0x0320`, `0x030E`)
   - Both Bluetooth wireless and wired USB cable links.

3. **No Background Apps Needed**:
   - Works at the driver level with zero CPU or RAM overhead.
   - Microsoft WHQL-compatible catalog signature.

---

### 📖 Installation Instructions:
1. Download **`Apple-Magic-Trackpad-Precision-Driver-v1.0.0.zip`** and extract it.
2. Right-click **`Install-Driver.bat`** and select **Run as administrator**.
3. Done! Windows will instantly configure your trackpad as a native Precision Touchpad.
4. Customize gesture direction and taps in Windows Settings.

*(To uninstall, simply right-click `Uninstall-Driver.bat` and run as administrator).*
