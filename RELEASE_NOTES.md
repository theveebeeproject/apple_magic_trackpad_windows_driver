# Apple Magic Trackpad Windows Precision Touchpad Driver v1.0.0

🎉 We are excited to announce the initial release of **Apple Magic Trackpad Windows Precision Touchpad Driver**!

This driver is a **100% native, driver-level solution** that transforms your Apple Magic Trackpad 2 & 3 into an official Windows Precision Touchpad (PTP). It gives you native Windows 10 & 11 gestures with **zero background software** or subscriptions like Magic Utilities.

---

### 📦 Download Assets
- **`Apple-Magic-Trackpad-Precision-Driver-v1.0.0.zip`** *(~250 KB)*
  Contains the driver package and 1-click automated installer/uninstaller scripts.

---

### 🚀 What's Included:
1. **Full Native Windows Precision Touchpad (PTP) Integration**:
   - 2-finger smooth scrolling & fluid pinch-to-zoom.
   - 3-finger swipe up for Task View (all open windows).
   - 3-finger swipe left/right to switch between apps (Alt+Tab).
   - 4-finger swipe to switch between Virtual Desktops.
   - Configurable directly inside **Windows Settings ➔ Bluetooth & devices ➔ Touchpad**.

2. **Broad Hardware Compatibility**:
   - Apple Magic Trackpad 3 USB-C (Late 2024 / M4 - PID `0x0324`)
   - Apple Magic Trackpad 3 & 2 Lightning (PID `0x0265`)
   - Apple Magic Trackpad 2 (PID `0x0320`, `0x030E`)
   - Both Bluetooth wireless and wired USB cable connections.

3. **Zero Background Overhead**:
   - Runs directly in the OS kernel driver stack.
   - 0% background CPU and 0 MB RAM usage.
   - Includes 1-click `Install-Driver.bat` and clean `Uninstall-Driver.bat`.

---

### 📖 Installation Instructions:
1. Download **`Apple-Magic-Trackpad-Precision-Driver-v1.0.0.zip`** below and extract it.
2. Right-click **`Install-Driver.bat`** ➔ **Run as administrator**.
3. Done! Windows will instantly configure your trackpad as a native Precision Touchpad.
4. Customize gesture direction and taps in Windows Settings.

*(To uninstall, simply right-click `Uninstall-Driver.bat` and run as administrator).*
