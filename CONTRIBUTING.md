# Contributing to Apple Magic Trackpad Windows Precision Touchpad Driver

Thank you for your interest in contributing to this project! We welcome feedback, hardware testing reports, documentation improvements, and pull requests.

## Code of Conduct
Please be polite, respectful, and collaborative. We aim to foster an open and welcoming community.

## How Can I Contribute?

### Reporting Bugs & Hardware Compatibility
Before submitting an issue, please search existing issues to avoid duplicates.
When submitting a bug report:
- Specify your Windows version and build (e.g., Windows 11 23H2 x64).
- State your trackpad hardware model (e.g., Magic Trackpad 3 USB-C, Magic Trackpad 2 Lightning).
- State connection mode (Bluetooth or USB-C cable).
- Provide steps to reproduce the issue.

### Suggesting Enhancements
Feature requests are tracked via GitHub issues. Clearly describe the scenario or hardware variation you wish to support.

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. Verify INF changes or installation script updates on a clean Windows machine.
3. Submit a pull request with a descriptive title and detailed summary of changes.

Thank you for helping make Apple Magic Trackpad on Windows great!
